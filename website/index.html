After installation

Join the temporary Wi-Fi network named Aura from your phone or computer. Enter your home Wi-Fi details. On the display, tap the settings icon to choose your city, brightness, units, language, and night mode.

The bottom buttons switch between daily and hourly forecasts. You can also tap the forecast list. In settings, swipe upward for language, location, and Wi-Fi reset.

If the device does not connect

Try another USB data cable and close applications using the same serial port. If needed, hold BOOT, press and release RESET, then release BOOT before reconnecting. Use the alternate color version only when the screen’s black and white are reversed.

What changed from Aura

White background, black text, a 48px main temperature, original ink weather artwork, compact forecast columns, and dedicated view and settings controls. Settings keep the same visual palette. The firmware also bounds location search results and checks forecast data before displaying it.

Built for the original ILI9341 / XPT2046 board. Compiled successfully; physical display and touch testing still needs your board.
